What the library handles for you

These previews run on shaderfield.js, the same file you download.

Palettes

Click a swatch to recolor the shader. You can also set any parameter as an HTML attribute.

palette="{{ pal }}"

Same frame every time

Drag the slider to move through time. A given time always draws the same frame, which is why video renders come out the same twice.

Any screen size

A shader resizes with its container and renders at the screen's pixel density, from a phone to a 4K display.
