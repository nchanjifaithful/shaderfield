Get started / Installation

Installation

Shaderfield is one file with no dependencies. Download it, add it to your project, then use it in any of three ways.

Download shaderfield.js

1. Website

Load the script and place the element. It fills its positioned parent, pauses off-screen and holds a still frame for reduced motion. Any parameter from a component's props table is an attribute.

{{ useWebCode }}

2. Motion video

Record a plate from any shader's Video tab, or render frame by frame inside Remotion or any frame loop. The same time value always gives the same frame.

const field = Shaderfield.mount(el, {
  effect: "skein", palette: "aurora", autoplay: false
});
field.render(frame / fps);

3. With AI

Open a shader, tune it, then copy from the AI prompt tab. Paste it into your coding agent with shaderfield.js in the project. The prompt carries the effect, palette, every value and the placement rules, for a website or a video plate.
