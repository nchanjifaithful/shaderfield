What the library handles for you

Four things you get without writing extra code. Every preview below runs on shaderfield.js, the same file you download.

01

Palettes

Every shader ships with colour palettes made for it. Click a swatch to recolor the preview, or set any palette and parameter as an HTML attribute.

palette="aurora"
palette="{{ pal }}"
02

Same frame every time

Time drives the picture, not the clock. Drag through the timeline: a given time always draws the same frame, so video renders come out identical every time.

field.render(seconds)
03

Any screen size

A shader fills its container and follows it as it resizes, rendering at the screen's pixel density from a phone up to a 4K display.

auto resize · up to 2× DPR
04

One file to install

Shaderfield is a single JavaScript file with no dependencies. Use it in plain HTML or in any framework that renders to the DOM.

<script src="shaderfield.js">
